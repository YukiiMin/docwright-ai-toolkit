**Docwright AI Toolkits** (`docwright-ai-toolkit`) is a specialized engineering toolkit for creating, inspecting, modifying, and validating **Word (`.docx`)** and **Excel (`.xlsx`)** files with deterministic layout and formula preservation.

## What Problems Does Docwright Solve?

1. **Multi-Page Word Table Integrity**: Automatically keeps rows from splitting across page boundaries, repeats table header rows on every new page, and locks section banners with their data.
2. **Style-Preserving Document Patching & Templates**: Heals fragmented Jinja2 tags (`{{ variable }}`) across XML runs and splices updated text into existing documents while preserving original fonts, colors, and corporate styles.
3. **1:1 Scanned PDF to Word Reconstruction**: Measures table grids from scanned PDFs using computer vision (`docx.measure_pdf_layout`), populates OCR text by cell ID, and compiles editable `.docx` forms.
4. **Token-Safe Spreadsheet Reading & 2D Block Mutation**: Extracts large workbooks into queryable structures without overflowing AI context windows, detects multiple tables on a single sheet, and inserts rows while automatically shifting downstream `=SUM(...)` and KPI formulas.

## Step 1: Install from PyPI

```bash
pip install docwright-ai-toolkit
```

## Step 2: Verify the 51-Tool Catalog

```bash
# List all 51 registered tools (19 docx.*, 31 xlsx.*, 1 common.*)
docwright list

# Inspect the input schema and runnable example for any tool
docwright schema docx.build_document
docwright schema xlsx.mutate_block
```
