## Kiến Trúc & 3 Phương Thức Sử Dụng

![Tổng quan Kiến trúc Docwright](/images/diagrams/architecture-overview.svg)

<CardGrid stagger>
	<Card title="1. Gọi Trực Tiếp Qua MCP Server" icon="rocket">
		Kết nối `docwright-mcp` vào Claude Code, Cursor, Google Antigravity, Claude Desktop hoặc Windsurf để AI tự động gọi 51 công cụ xử lý tài liệu.
	</Card>
	<Card title="2. Import Thư Viện Python SDK" icon="seti:python">
		Import trực tiếp `doctools.api` và `doctools.operations` vào dự án Python của bạn để đọc bảng tính, chèn khối 2D tự động dịch công thức và xuất file Word.
	</Card>
	<Card title="3. Chạy Lệnh CLI Tốc Độ Cao" icon="terminal">
		Sử dụng `docwright list`, `docwright schema`, `docwright compact-json` hoặc chạy bất kỳ công cụ nào từ Terminal và CI/CD với mã thoát POSIX chuẩn.
	</Card>
	<Card title="51 Công Cụ Thực Chiến" icon="approve-check-circle">
		Bao gồm **19 công cụ Word (`docx.*`)**, **31 công cụ Excel (`xlsx.*`)**, và **1 công cụ Nén Token (`common.*`)** tích hợp sẵn kiểm định chất lượng.
	</Card>
</CardGrid>
