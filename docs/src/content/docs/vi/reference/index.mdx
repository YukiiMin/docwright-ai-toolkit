Docwright AI Toolkits cung cấp **51 công cụ chuyên biệt** thuộc **2 mô-đun tài liệu cốt lõi** (`docx.*`, `xlsx.*`) và **1 mô-đun tiện ích** (`common.*`).

- **[Công Cụ Word (`docx.*` — 19 Tools)](/vi/reference/docx-tools/)**: Khởi tạo tài liệu từ DocSpec, điền biểu mẫu Jinja, vá văn bản bảo toàn định dạng, trích xuất cấu trúc và tái tạo biểu mẫu từ PDF scan.
- **[Công Cụ Excel (`xlsx.*` — 31 Tools)](/vi/reference/xlsx-tools/)**: Trích xuất dữ liệu 3 tầng, nhận diện đảo bảng 2D, chèn khối tự động dịch chuyển vùng công thức, tính toán lại qua LibreOffice và kiểm định chất lượng.
- **[Tiện Ích Chung, CLI & Python SDK (`common.*` — 1 Tool)](/vi/reference/common-and-sdk/)**: Nén JSON tiết kiệm token, các lệnh CLI và thư viện `doctools.api`.
