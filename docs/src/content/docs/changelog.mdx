## v1.0.0 (2026-10-15)

### Initial Release
- **Protected Binary Engine + Open Contract Architecture**: Compiled 111 core engine modules into native C-Extensions (`.pyd`) while keeping 18 Pydantic contract and CLI/MCP entrypoint files open for AI schema inspection.
- **Word (`docx.*`) Module (19 Tools)**:
  - `DocSpec` programmatic document builder with ECMA-376 canonical element ordering.
  - Multi-page table pagination protection (repeating headers, zero split rows, anti-orphan section banners).
  - Jinja2 template run healer (`docx.normalize_template`) and renderer (`docx.render_template`).
  - Style-preserving surgical run patcher (`docx.patch`).
  - Scanned PDF to 1:1 editable Word reconstruction pipeline (`docx.measure_pdf_layout`, `docx.populate_layout_text`, `docx.compile_layout_spec`).
- **Spreadsheet (`xlsx.*`) Module (31 Tools)**:
  - 3-tier faithful workbook extraction and slice querying (`xlsx.extract`, `xlsx.query`, `xlsx.semantic_extract`).
  - 2D Table Island detector (`xlsx.detect_tables`) and block mutator (`xlsx.mutate_block`, `xlsx.shift_block`) with automatic AST formula range shifting.
  - Headless LibreOffice formula cache recalculation (`xlsx.recalc`) and 13 automated quality checks (`xlsx.validate`).
- **Common Utilities (`common.*`) (1 Tool)**:
  - `common.compact_json` for token-saving JSON minification and sub-path extraction.
