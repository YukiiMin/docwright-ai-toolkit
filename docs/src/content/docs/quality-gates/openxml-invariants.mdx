title: OpenXML Error Invariants & Codes
description: Complete diagnostic catalog for Word and OpenXML structural invariants.
---

When validating Word documents, Docwright evaluates against strict OpenXML structural invariants:

| Code | Invariant Description | Root Cause | Automatic Engine Resolution |
|---|---|---|---|
| `ERR_DOCX_001` | **Last Paragraph Rule** | Empty cell lacks terminating `<w:p>`. | Automatically appends `<w:p/>` to every `<w:tc>`. |
| `ERR_DOCX_002` | **Run Text Overwrite** | Direct assignment to `cell.text` strips styling. | Mutates text strictly through `runs` via Surgical Splicer. |
| `ERR_DOCX_003` | **Table Row Split** | Multi-page tables lack `<w:cantSplit/>` / `<w:tblHeader/>`. | Automatically injects attributes on all multi-page tables. |
| `ERR_DOCX_004` | **Invalid Tag Ordering** | Child tags inside `<w:tcPr>` violate ECMA-376 schema order. | Enforces canonical insertion order via `TagOrderRegistry`. |
| `ERR_DOCX_005` | **Image Margin Overflow** | Image width exceeds printable page boundary. | Dynamically computes maximum width from `<w:pgSz>` & `<w:pgMar>`. |
| `ERR_DOCX_006` | **Orphaned Section Banner** | Heading row placed at bottom of page without content. | Injects `<w:keepNext/>` to bind heading to next table row. |

## Validating via CLI

```bash
docwright docx.validate --spec '{"file_path": "report.docx"}'
```
