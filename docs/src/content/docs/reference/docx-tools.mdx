This page documents all **19 registered `docx.*` tools** available in Docwright AI Toolkits. Every tool can be invoked via **MCP** (`docx.<tool>` or `docx_<tool>`), **CLI** (`docwright docx.<tool> --spec payload.json`), or **Python SDK** (`from doctools.operations.docx import docx_<tool>`).

## `docx.inspect_structure`

Inspect Word document structure tree with stable anchor coordinates for AI analysis and editing.

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `file_ref` | `string / object` | **Yes** | Path to Word document (.docx) or FileRef URI (e.g. 'file:///...' or local relative/absolute path) |

**Usage Examples (MCP / CLI / Python SDK):**

```bash
# 1. CLI Execution
docwright docx.inspect_structure --json '{"file_ref": "sample_file_ref.docx"}'
```

```python
# 2. Python SDK Import
from doctools.operations.docx import docx_inspect_structure
res = docx_inspect_structure(**{
  "file_ref": "sample_file_ref.docx"
})
print(res.success, res.result)
```
