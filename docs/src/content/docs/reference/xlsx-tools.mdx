This page documents all **31 registered `xlsx.*` tools** available in Docwright AI Toolkits. Every tool can be invoked via **MCP** (`xlsx.<tool>` or `xlsx_<tool>`), **CLI** (`docwright xlsx.<tool> --spec payload.json`), or **Python SDK** (`from doctools.operations.xlsx import xlsx_<tool>` or `from doctools.api import ...`).

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
