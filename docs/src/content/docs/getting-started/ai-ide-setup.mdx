---
title: 1-Click AI IDE & Agent Setup
description: Connect Docwright MCP Server to Claude Code, Cursor, Google Antigravity, Claude Desktop, Windsurf, and OpenAI Codex CLI.
---

Every supported AI IDE and coding agent connects to the same stdio server entrypoint (`docwright-mcp`) or CLI (`docwright`).

---

## <img src="/images/icons/claude-code.svg" alt="Claude Code" width="28" height="28" style="vertical-align: middle; margin-right: 8px;" /> 1. Claude Code (Anthropic CLI)

Register `docwright` directly via the Claude Code CLI:

```bash
claude mcp add docwright -- docwright-mcp
```

---

## <img src="/images/icons/cursor.svg" alt="Cursor" width="28" height="28" style="vertical-align: middle; margin-right: 8px;" /> 2. Cursor IDE

Create or update `.cursor/mcp.json` in your project root:

```json
{
  "mcpServers": {
    "docwright": {
      "command": "docwright-mcp",
      "args": []
    }
  }
}
```

---

## <img src="/images/icons/antigravity.svg" alt="Google Antigravity" width="28" height="28" style="vertical-align: middle; margin-right: 8px;" /> 3. Google Antigravity IDE

Add to `.agents/mcp_config.json` in your workspace or `~/.gemini/config/mcp_config.json`:

```json
{

    "docwright": {
      "command": "docwright-mcp",
      "args": []

  }
```

## <img src="/images/icons/openai-codex.svg" alt="OpenAI Codex CLI" width="28" height="28" style="vertical-align: middle; margin-right: 8px;" /> 6. OpenAI Codex CLI / Terminal Agents

Terminal-based agents can invoke the CLI directly with deterministic JSON output:

```bash
docwright list
docwright schema xlsx.mutate_block
docwright docx.build_document --spec spec.json
```

---

## <img src="/images/icons/mcp-universal.svg" alt="Universal MCP" width="28" height="28" style="vertical-align: middle; margin-right: 8px;" /> 7. Continue.dev, Cline, Roo Code & Zed

Use the standard stdio command `"command": "docwright-mcp"` with `"args": []` in your client's MCP settings file. Pre-made config files are available in the [`configs/`](https://github.com/YukiiMin/docwright-ai-toolkit/tree/main/configs) directory on GitHub.
