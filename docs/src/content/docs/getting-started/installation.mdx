## 1. Python & Operating System Requirements

- **Python**: `>= 3.10` (Python `3.11`, `3.12`, or `3.13` recommended).
- **Packages**: Pre-compiled binary wheels are published on PyPI alongside open Pydantic contract schemas.

```bash
pip install --upgrade docwright-ai-toolkit
```

Verify the CLI entrypoints after installation:

```bash
docwright list
docwright-mcp --help
```

---

## 2. Optional: LibreOffice for Formula Recalculation (`xlsx.recalc`)

When modifying Excel spreadsheets, `xlsx.mutate` and `xlsx.mutate_block` update formula strings automatically. If your workflow requires refreshing cached formula evaluation results (`<v>` tags) without opening Microsoft Excel, install **LibreOffice** so `xlsx.recalc` can run headless evaluation:

- **Windows**: `winget install TheDocumentFoundation.LibreOffice`
- **macOS**: `brew install --cask libreoffice`
- **Ubuntu / Debian**: `sudo apt-get install -y libreoffice-calc`
