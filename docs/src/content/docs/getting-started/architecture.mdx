## Truthful Module Inventory (51 Tools Total)

Docwright consists of **2 core document engineering modules** and **1 common utility module**:

| Module Namespace | Registered Tools | Primary Capabilities |
| :--- | :--- | :--- |
| **Word Module (`docx.*`)** | **19 Tools** | Declarative `DocSpec` generation, Jinja2 template normalization & rendering, style-preserving run patching, 2-tier faithful extraction, and computer-vision scanned PDF layout reconstruction. |
| **Excel Module (`xlsx.*`)** | **31 Tools** | 3-tier faithful extraction (`extract`/`query`), 2D Table Island detection, block row/column insertion with automatic formula range shifting, headless LibreOffice recalculation, and 13 quality validation gates. |
| **Common Module (`common.*`)** | **1 Tool** | High-efficiency JSON minification and subtree pruning (`common.compact_json`) to minimize LLM token consumption. |

## Standardized `ResultEnvelope` Contract

Every tool execution across MCP, Python SDK, and CLI returns a uniform `ResultEnvelope` object:

```json
{
  "success": true,
  "result": {
    "output_path": "output/report_verified.docx",
    "tables_built": 2
  },
  "diagnostics": {
    "errors": [],
    "warnings": [],
    "info": [
      {
        "code": "DOCX_BUILD_OK",
        "message": "Document built and verified cleanly."
      }
    ]
  }
}
```
