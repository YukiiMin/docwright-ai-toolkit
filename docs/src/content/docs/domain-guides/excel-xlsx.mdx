## 1. 2D Block Insertion & Automatic Formula Range Shifting

In real-world financial and operational spreadsheets, summary rows (`=SUM(C2:C3)`, `=AVERAGE(...)`, `=COUNTIF(...)`) sit below data tables, or multiple tables sit on the same worksheet.

When you insert new rows using `xlsx.mutate_block`, Docwright's **AST Formula Shifter** parses every formula in the workbook and automatically expands or shifts coordinate ranges (`=SUM(C2:C3)` becomes `=SUM(C2:C5)`), while cloning the exact cell styles, number formats, and borders from adjacent template rows.

## 2. Token-Safe 3-Tier Spreadsheet Reading

Instead of dumping tens of thousands of raw XML cells into an LLM prompt, use Docwright's 3-tier reading workflow:

1. **Preflight & Topology (`xlsx.preflight`, `xlsx.detect_tables`)**: Quickly scan sheet names, dimensions, and detect independent 2D **Table Islands** on each sheet.
2. **Faithful Extraction (`xlsx.extract`, `xlsx.semantic_extract`)**: Parse the workbook into a cached model in the local `FileStore` and return a lightweight structural summary.
3. **Targeted Slice Query (`xlsx.query`)**: Fetch only the specific sheet, cell range (`A1:G25`), or table island needed for the task.

```python
from doctools.operations.xlsx import xlsx_detect_tables, xlsx_extract, xlsx_query

# 1. Detect all distinct tables on a worksheet
tables = xlsx_detect_tables(file_ref="data/operations_master.xlsx", sheet_name="Q3_KPIs")
print("Detected table islands:", tables.result)

# 2. Extract workbook into FileStore and query a specific slice
ext = xlsx_extract(file_ref="data/operations_master.xlsx")
slice_data = xlsx_query(
    file_ref="data/operations_master.xlsx",
    sheet_name="Q3_KPIs",
    cell_range="A1:F20",
)
```

## 3. Recalculation & 13 Quality Validation Gates

After mutating a workbook with `xlsx.mutate`, `xlsx.mutate_block`, or `xlsx.batch_interact`:
- Run **`xlsx.recalc`** to evaluate live formula caches via headless LibreOffice.
- Run **`xlsx.validate`** to verify the workbook against 13 automated quality checks (checking for formula `#REF!`/`#NAME?` errors, broken merged cell borders, uncalculated formula caches, and DrawingML preservation).
