---
title: "Cookbook: Multi-Page Executive Report"
description: Generate a multi-page Word report with repeating table headers, custom column widths, and automated quality validation.
---

This cookbook shows how to build a structured multi-page Word document using `docx.build_document` and verify it with `docx.validate` across **CLI** and **Python SDK**.

## 1. Prepare the `DocSpec` Payload (`report_spec.json`)

```json
{
  "output_path": "output/q4_architecture_review.docx",
  "spec": {
    "page_setup": {
      "orientation": "portrait",
      "margin_top_cm": 2.0,
      "margin_bottom_cm": 2.0,
      "margin_left_cm": 2.5,
      "margin_right_cm": 2.0
    },
    "default_font_name": "Times New Roman",
    "default_font_size_pt": 11,
    "blocks": [
      {
        "type": "heading",
        "level": 1,
        "text": "Q4 Architecture & Security Review"
      },
      {
        "type": "paragraph",
        "text": "Summary of platform deliverables and verification status across engineering teams.",
        "space_after_pt": 8
      },
      {
        "type": "table",
        "col_widths_cm": [2.0, 5.5, 4.0, 5.0],
        "header_rows": 1,
        "rows": [
          ["ID", "Deliverable", "Owner", "Verification Status"],
          ["ARC-01", "Binary C-Extension Packaging", "Platform Team", "Passed (0 leaked sources)"],
          ["ARC-02", "Multi-Page Table Pagination Engine", "DOCX Core", "Passed (Headers repeat cleanly)"],
          ["ARC-03", "2D Block Formula AST Shifter", "XLSX Core", "Passed (SUM ranges updated)"]
        ]
      }
    ]
  }
}
```

## 2. Run via CLI or Python SDK

```bash
# Option A: CLI Execution
docwright docx.build_document --spec report_spec.json
docwright docx.validate --json '{"file_ref": "output/q4_architecture_review.docx"}'
```

```python
# Option B: Python SDK Execution
import json
from doctools.operations.docx import docx_build_document, docx_validate

payload = json.loads(open("report_spec.json", encoding="utf-8").read())
build_res = docx_build_document(**payload)
val_res = docx_validate(file_ref="output/q4_architecture_review.docx")
print("Success:", build_res.success and val_res.success)
```
