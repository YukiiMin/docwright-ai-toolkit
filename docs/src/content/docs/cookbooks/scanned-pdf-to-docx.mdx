---
title: "Cookbook: Scanned PDF to 1:1 Editable Word Form"
description: Reconstruct a scanned multi-page PDF questionnaire or form into an editable Word document using Docwright's 3-step vision pipeline.
---

When working with scanned PDF forms or questionnaires, converting directly via standard OCR often loses table grid alignment and splits multi-line questions across page breaks. Docwright provides a deterministic 3-step pipeline:

1. **`docx.measure_pdf_layout`**: Measures exact page geometry, table bounding boxes, column ratios, and cell coordinates (`c0_0`, `c0_1`, ...) from the PDF pages.
2. **`docx.populate_layout_text`**: Populates cell text by `cell_id` (supporting vertical `row_span` and horizontal `col_span`).
3. **`docx.compile_layout_spec`**: Compiles the populated `LayoutSpec` into an editable `.docx` file.

---

## Python SDK End-to-End Example

```python
from doctools.operations.docx import (
    docx_measure_pdf_layout,
    docx_populate_layout_text,
    docx_compile_layout_spec,
    docx_validate,
)

# Step 1: Measure table grid geometry from the scanned PDF
measured = docx_measure_pdf_layout(
    pdf_path="scans/survey_form.pdf",
    output_layout_path="scratch/survey_layout.json",
    dpi=200,
)

# Step 2: Populate transcribed text mapped to deterministic cell IDs
populated = docx_populate_layout_text(
    layout_spec_path="scratch/survey_layout.json",
    output_path="scratch/survey_populated.json",
    pages_text={
        "1": {
            "tables": [
                {
                    "table_index": 0,
                    "cells": {
                        "c0_0": {"text": "Question / Topic", "bold": True, "align": "center"},
                        "c0_1": {"text": "Response Notes", "bold": True, "align": "center"},
                        "c1_0": {"text": "1. Primary Operational Bottlenecks", "bold": True},
                        "c1_1": {"text": "", "row_span": 2},
                        "c2_0": {"text": "** Hint: Describe frequency and impact", "italic": True},
                    },
                }
            ]
        }
    },
)

# Step 3: Compile into an editable Word document
compiled = docx_compile_layout_spec(
    layout_spec_path="scratch/survey_populated.json",
    output_path="output/survey_reconstructed.docx",
    merge_continued_tables=False,
)

# Step 4: Run quality verification
validation = docx_validate(file_ref="output/survey_reconstructed.docx")
print("Reconstruction verified:", validation.success)
```
