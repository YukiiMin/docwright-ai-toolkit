This cookbook demonstrates how to safely expand an existing table inside a multi-table Excel sheet without breaking downstream `=SUM(...)` formulas or overwriting adjacent tables.

![2D Block Mutation Workflow](/images/diagrams/xlsx-block-mutation.svg)

---

## End-to-End Python SDK Workflow

```python
from doctools.operations.xlsx import (
    xlsx_detect_tables,
    xlsx_mutate_block,
    xlsx_recalc,
    xlsx_validate,
)

# Step 1: Detect all 2D Table Islands on the target sheet
islands_res = xlsx_detect_tables(
    file_ref="templates/financial_model.xlsx",
    sheet_name="Operating_Expenses",
)
print("Detected tables:", islands_res.result)

# Step 2: Insert 2 new rows into the table and shift all downstream formulas
mut_res = xlsx_mutate_block(
    file_ref="templates/financial_model.xlsx",
    output_path="output/financial_model_q4.xlsx",
    sheet_name="Operating_Expenses",
    operation="insert_rows",
    start_row=6,
    count=2,
    data=[
        ["OPEX-09", "Cloud GPU Cluster", "Engineering", 14500],
        ["OPEX-10", "Automated QA Pipeline", "Engineering", 3200],
    ],
)

# Step 3: Recalculate cached formula values via headless LibreOffice
xlsx_recalc(file_ref="output/financial_model_q4.xlsx")

# Step 4: Validate against all 13 spreadsheet quality gates
val_res = xlsx_validate(file_ref="output/financial_model_q4.xlsx")
print("Validation passed:", val_res.success)
```
